# Security and privacy

Do not submit real identity images, OCR results, credentials or live infrastructure details to public issues. Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/boreaslol/ine-ocr/security/advisories/new). If private reporting is unavailable, open a public issue containing only a request for a private contact channel, without vulnerability details or personal data.

The default service is authenticated and loopback-bound. Deployment operators remain responsible for TLS, network restrictions, user authorization/consent, token rotation, log retention and host updates. Model outputs and document check digits are not an authentication or identity-verification mechanism.
